# Sprint
Sprint is a unified hackathon dashboard for the next generation of Hack Club Events. Featuring Hack Club, GitHub, and Slack integration, this site simplifies the process of running and attending a hackathon.
This project was started in April of 2026 and has been in development since. It is now in beta at pianoman0.com/sprint - go check it out!
